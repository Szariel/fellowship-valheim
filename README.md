# Fellowship Launcher

[Aktuellen Launcher herunterladen](https://github.com/Szariel/fellowship-valheim/releases/latest)

Valheim-Launcher mit separatem Modprofil, gemeinsamem Modsync und automatischen Launcher-Updates.

## Start

1. `Fellowship-Launcher-Setup-0.2.1.exe` installieren und Fellowship Launcher öffnen.
2. In den Einstellungen als gemeinsamen Modpaket-Link eintragen:
   https://github.com/Szariel/fellowship-valheim/releases/latest/download/Fellowship-Modpack.zip
3. Steam starten, **Abgleichen** wählen und anschließend **Portal öffnen**.

Alternativ das vollständige ZIP herunterladen und das enthaltene Modpaket lokal importieren.

Bestehende Fellowship-Profile bleiben erhalten. Launcher 0.1.x muss einmal durch dieses Setup ersetzt werden. Ab 0.2.x werden neue Launcher-Versionen automatisch geprüft und heruntergeladen; die Installation erfolgt per Neustart-Schaltfläche.

## Enthalten

- Aktuelles Modpaket mit BossFinder 1.1.2, Lootheim sowie den bisherigen Mods und gemeinsamen Einstellungen.
- Persönliche Configs für Configuration Manager, BetterUI, Movable Inventory Windows, Compass and Clock und Lootheim bleiben bei neuen Paketversionen erhalten.
- RestedPlus: Schaden 5/10/15/20 %, Bewegung 0/5/10/15 % bei Komfort 5/10/15/20.
- Einzelner Valhalla-Spruch und Portal-Fortschrittsanzeige.

Windows x64 / Steam. Inoffiziell und nicht digital signiert. Mods stammen von ihren jeweiligen Autoren. Keine Spielstände oder Spielinstallation enthalten.

Prüfung: 18 automatisierte Tests, Oberflächentest und echter Update-Download mit Prüfsummenprüfung gegen eine lokale Testquelle. BossFinder und Lootheim sind installiert, aber noch nicht im Spiel getestet.
