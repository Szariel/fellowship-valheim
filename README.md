# Fellowship Valheim

Gemeinsamer Valheim-Launcher und Modpaket-Downloads.

Die Windows-Anwendung und das dazugehörige Modpaket stehen in den Releases bereit.
Im Launcher kann der direkte Paketlink hinterlegt werden:

https://github.com/Szariel/fellowship-valheim/releases/latest/download/Fellowship-Modpack.zip

Der Launcher nutzt ein eigenes Modprofil außerhalb des Steam-Spielordners.
Valheim selbst und Spielstände werden nicht mitgeliefert.
